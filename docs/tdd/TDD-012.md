## Context & Goals

### Problem

Admin cần tạo hồ sơ thành viên mới trong hệ thống VNZ. Việc tạo hồ sơ đồng thời tạo tài khoản đăng nhập; thành viên mới luôn đang làm việc và chưa được đăng trên website.

### Goals

- Tạo User mới từ form quản lý thành viên.
- Admin nhập Email và thông tin hồ sơ bắt buộc.
- Tạo PasswordHash từ mật khẩu mặc định cố định Vnz@123456.
- Không trả mật khẩu hoặc PasswordHash trong response.
- Gán RoleId = null khi tạo.
- Mặc định IsActive = true để tài khoản mới có thể đăng nhập.
- Mặc định EmploymentStatus = Working.
- Mặc định IsPublished = false và DisplayOrder = null.
- Ghi CreatedBy là Admin hiện tại và ghi CreateAt/UpdatedAt.
- Lưu hồ sơ và tài khoản trong một transaction.

### Non-goals

- Không cho Admin chọn EmploymentStatus hoặc IsPublished trong form tạo.
- Không tự động đăng thành viên lên website.
- Không gán Role khi tạo; RoleId để null.
- Không quản lý chỉnh sửa hồ sơ sau khi tạo.
- Không gọi external API.

## Architecture

~~~mermaid
flowchart LR
  Admin[Admin UI Form] --> API[Member Create API]
  API --> Auth[Authentication/Authorization]
  API --> Svc[Member Create Service]
  Svc --> Validator[Member Validator]
  Svc --> Hasher[Password Hasher]
  Svc --> Repo[User Repository/AppDbContext]
  Repo --> DB[(PostgreSQL)]
  Public[Public Website] --> DB
~~~

User là entity dùng đồng thời cho hồ sơ thành viên và tài khoản đăng nhập. Service nhận dữ liệu hồ sơ, validate, hash mật khẩu mặc định, thiết lập trạng thái hệ thống và ghi User trong một transaction. User mới có `RoleId=null` vẫn được phép đăng nhập khi `IsActive=true`, nhưng token không có role Admin nên không truy cập endpoint quản trị. Public website chỉ đọc User có IsPublished=true; User mới luôn false nên không xuất hiện public.

## Internal API

### Endpoints

- POST /api/v1/admin/members — tạo hồ sơ thành viên và tài khoản đăng nhập.
- Actor: Admin đã xác thực.
- Body FullName: string, required, trim, không rỗng.
- Body Email: string, required, trim, email format, unique, dùng để đăng nhập.
- Body Position: string, required, trim, không rỗng.
- Body JobLevel: JobLevel, required, enum hợp lệ.
- Body JoinedDate: DateTime, required, datetime hợp lệ.
- Body AvatarUrl, AnimationUrl, AudioUrl, Hometown, Hobbies, PersonalQuote: optional string, có thể null.
- Không nhận RoleId, EmploymentStatus, IsPublished hoặc DisplayOrder từ client; nếu gửi các field này thì reject theo unknown-field/policy hiện tại.
- Server gán RoleId null, IsActive true, EmploymentStatus Working, IsPublished false và DisplayOrder null.
- Server gán CreatedBy từ Admin hiện tại, không tin CreatedBy từ request.
- Mật khẩu mặc định không nhận từ client; server hash literal Vnz@123456.
- Validation phải hoàn tất trước transaction và password hashing có thể thực hiện trước khi ghi.
- Success response không chứa PasswordHash hoặc plaintext password.

### Examples

#### Tạo thành viên với field bắt buộc

~~~json
{
  "fullName": "Nguyễn Văn A",
  "email": "a@vnz.vn",
  "position": "Backend Developer",
  "jobLevel": "Junior",
  "joinedDate": "2026-09-21"
}
~~~

HTTP 201; User được tạo với IsActive true, EmploymentStatus Working, IsPublished false, DisplayOrder null và RoleId null. User có thể đăng nhập bằng email và mật khẩu mặc định, nhưng không có quyền Admin khi RoleId vẫn null.

#### Tạo thành viên với field bổ sung

HTTP 201; AvatarUrl, AnimationUrl, AudioUrl, Hometown, Hobbies và PersonalQuote được lưu theo giá trị hợp lệ.

#### Thiếu field bắt buộc

HTTP 400 MEMBER_VALIDATION_ERROR; response chỉ rõ field thiếu; không tạo User.

#### Email sai format hoặc đã tồn tại

Email sai format trả HTTP 400 MEMBER_VALIDATION_ERROR. Email đã tồn tại trả HTTP 409 MEMBER_EMAIL_EXISTS. Không tạo User mới.

#### Client cố gửi trạng thái hoặc Role

Request có RoleId, EmploymentStatus, IsPublished hoặc DisplayOrder do client tự chọn bị từ chối hoặc bỏ theo unknown-field policy đã thống nhất; không được dùng các giá trị đó để override default server.

#### Hủy form

Hủy ở UI không gọi POST và không tạo User.

#### Persistence failure

HTTP 500 MEMBER_CREATE_FAILED; rollback transaction, User không xuất hiện trong danh sách.

#### Authentication/authorization failure

HTTP 401 khi chưa xác thực; HTTP 403 khi không có quyền Admin. Không ghi database.

### Error Codes

- AUTHENTICATION_REQUIRED (401): thiếu hoặc sai phiên đăng nhập.
- FORBIDDEN (403): người dùng không có quyền Admin.
- MEMBER_VALIDATION_ERROR (400): thiếu/sai FullName, Email, Position, JobLevel, JoinedDate hoặc field format không hợp lệ.
- MEMBER_EMAIL_EXISTS (409): Email đã được dùng cho User khác.
- MEMBER_CREATE_FAILED (500): persistence/transaction failure; rollback toàn bộ.
