# Project documents

Thư mục này dùng để lưu các tài liệu Markdown trước khi kiểm tra trên IDE và map lên Document First.

## Cấu trúc

- `tdd/`: Technical Design Document
- `user-stories/`: User Story
- `business-rules/`: Business Rule
- `tests/`: Unit Test và System Test

Mỗi tài liệu nên dùng một file `.md` riêng, với mã tài liệu trong tên file, ví dụ `TDD-017-feature-name.md`.
