## Trạng thái metadata chưa hoàn thiện

Owner, Reviewer, Approver và Effective Date chưa được cung cấp nên các BR vẫn là bản Draft và giữ placeholder/để trống theo template. Version để trống vì hệ thống quản lý phiên bản.
